# Invoice & Vendor Follow-up config
- `window_days: 120`
- `buckets: 0-14, 15-30, 31-60, 60+`

## Chase ladder
- 15-30: gentle, "checking this reached you"
- 31-60: firm, restate the reference and amount, ask for a date
- 60+: escalate to a named person, draft only, never send

## Never chase
Counterparties handled by a person. The skill lists them as excluded and writes no draft.
