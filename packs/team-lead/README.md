# Team Lead

3 bots. Generated from the skills on disk by `tools/build_readmes.py`; do not edit by hand.

| Bot | What it owns |
|---|---|
| [`one-to-one-prep`](one-to-one-prep/) | Prepares a brief for a one-to-one with a named person: their open items, what they raised recently, what you owe them, and what has gone unanswered… |
| [`project-decomposer`](project-decomposer/) | Breaks a project, initiative or goal into owned tasks, each carrying its own verification criteria and a named owner, and returns one Adaptive Card… |
| [`team-lead-mode`](team-lead-mode/) | The orchestrator for a team lead's week. |

## Installing this pack

Each bot is a separate archive. Download the ones you want from `dist/`, then in Cowork: **Customize** → **Skills** → the arrow next to **Add** → **Upload skill**. Cowork validates each file and writes it to your OneDrive.

This pack costs **3 of your 50 custom skills**. Scheduling is optional on every bot; each schedule you create costs one of your 25.
