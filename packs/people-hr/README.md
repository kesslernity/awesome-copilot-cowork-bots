# People & HR

3 bots. Generated from the skills on disk by `tools/build_readmes.py`; do not edit by hand.

| Bot | What it owns |
|---|---|
| [`internal-expert-finder`](internal-expert-finder/) | Finds who inside the organisation has already done a given kind of work, with the evidence for each name, and drafts the introduction. |
| [`interview-loop-coordinator`](interview-loop-coordinator/) | Prepares an interview loop: who covers which competency, what each interviewer needs beforehand, and a consolidated feedback pack afterwards scored… |
| [`onboarding-buddy`](onboarding-buddy/) | Builds a dated first-fortnight plan for a new joiner from the team's own documents, meetings and systems, naming who they meet and what they read on… |

## Installing this pack

Each bot is a separate archive. Download the ones you want from `dist/`, then in Cowork: **Customize** → **Skills** → the arrow next to **Add** → **Upload skill**. Cowork validates each file and writes it to your OneDrive.

This pack costs **3 of your 50 custom skills**. Scheduling is optional on every bot; each schedule you create costs one of your 25.
